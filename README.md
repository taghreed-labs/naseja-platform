# 🧵 Naseja Platform (منصة نسيجة)

## 📌 About The Project (نبذة عن المشروع)
**Naseja** is a digital directory and service-request platform built to connect clients with local artisans and productive families. It serves as a discovery and booking hub where users can browse handmade products, request services, and coordinate directly.

منصة **نسيجة** هي منصة رقمية متكاملة تهدف إلى ربط العملاء بالأسر المنتجة والحرفيين. تعمل المنصة كدليل لاكتشاف الحرف اليدوية وطلب الخدمات والتنسيق المباشر بين الطرفين.

---

## 🚀 Key Features (المميزات الرئيسية)
- **Role-Based Authentication:** Support for different user types (Clients & Artisans/Makers) with secure role management.
- **Service Discovery & Filtering:** Advanced search and filter options to explore artisans by category and location.
- **Request & Booking System:** Allows clients to submit service requests and track their status (`Pending`, `Accepted`, `Completed`).
- **Order-Linked Chat System:** A built-in direct text messaging system linked exclusively to specific service requests.
- **Security & Validation:** Protected with Form Requests, CSRF protection, and secure data hashing.

---

## 🛠️ Tech Stack (التقنيات المستخدمة)
- **Backend:** PHP / Laravel Framework
- **Database:** MySQL / PostgreSQL (managed via Eloquent ORM & Migrations)
- **Frontend:** Blade Templates, HTML5, CSS3, JavaScript / Tailwind CSS
- **Version Control:** Git & GitHub
